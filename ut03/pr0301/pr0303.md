4. Contar números pares del 1 al 20 con while:
Usa while para mostrar los números pares entre 1 y 20.

Hacemos el script:
```bash
#!/bin/bash

num=1

while [ $num -le 20 ]
do
        if [ $(( num % 2 )) -eq 0 ]; then
                echo $num
        fi

        num=$(( $num+1 ))
done
```

5. Suma de dígitos
Pide un número al usuario y usa while para sumar todos sus dígitos. Por ejemplo, 123 debería devolver 6.

Hacemos el script:
```bash
#!/bin/bash

echo "Inserta un número y sumaremos sus dígitos:"
read num
suma=0

while [ $num -gt 0 ]
do

        digito=$(( num % 10 ))

        suma=$(( suma + digito ))

        num=$(( num / 10 ))

done

echo "La suma de los dígitos es: $suma"
```

6. Cuenta regresiva
Pide al usuario un número inicial y usa until para hacer una cuenta regresiva hasta llegar a cero.

Hacemos el script:
```bash
#!/bin/bash

echo "Inserta un número y haremos la cuenta regresiva"
read num

until [ $num -lt 0 ]
do
        echo "$num"
        num=$(( num-1 ))
done
```

9. Verificar contraseña
Usa until para pedir al usuario que ingrese una contraseña correcta, y repite hasta que la acierte.

Hacemos el script:
```bash
#!/bin/bash

buena=1234

echo "Introduce la contraseña:"
read contra

until [ $contra = $buena ]
do

        echo "Contraseña incorrecta. Vuelve a intentarlo"
        read contra

done

echo "Contraseña correcta"
```
