Ejercicio 1: Contar líneas de un archivo
Escribe un script que solicite el nombre de un archivo y luego imprima cuántas líneas tiene ese archivo. Verifica que el archivo exista antes de contar las líneas.

Creo el fichero para el script:
```bash
cesar@crb-server:~$ touch script1.sh
cesar@crb-server:~$ ls
pr0201  script1.sh
```

Compruebo el contenido de mi fichero conejillo de indias:
```bash
cesar@crb-server:~$ cat pr0201/file
bliblablu
blublabli
cesar@crb-server:~$
```

Añado al script1.sh:

```bash
#!/bin/bash
echo "Ingrese el nombre del archivo con su ruta:"
read archivo

if [ -f $archivo ]; then
        echo "El archivo tiene el siguiente número de líneas:"
        wc -l $archivo
else
        echo "El archivo no existe"
fi
```

```bash

Ingrese el nombre del archivo con su ruta:

root@crb-server:/home/cesar#
```

Ejercicio 3: Comparación de dos números
Realiza un script que solicite dos números al usuario y los compare, mostrando cuál es mayor, o si son iguales.

Para solicitar al usuario que tiene que introducir un valor por teclado tienes que utilizar el comando read tal como se muestra en el siguiente ejemplo:

read -p "Introduce tu usuario: " usuario
echo Bienvenido, $usuario

Hacemos el script:

```bash
#!/bin/bash
echo "Ingrese el primer número:"
read primernum
echo "Ingrese el segundo número:"
read segundonum

if [ $primernum -eq $segundonum ]; then
        echo "$primernum es igual a $segundonum"
else

        if [ $primernum -gt $segundonum ]; then
                echo "$primernum es mayor que $segundonum"
        else
                echo "$primernum es menor que $segundonum"
        fi
fi
```

Comprobamos el funcionamiento:

```bash
cesar@crb-server:~$ ./script3.sh
Ingrese el primer número:
2
Ingrese el segundo número:
2
2 es igual a 2
cesar@crb-server:~$ ./script3.sh
Ingrese el primer número:
5
Ingrese el segundo número:
2
5 es mayor que 2
cesar@crb-server:~$ ./script3.sh
Ingrese el primer número:
2
Ingrese el segundo número:
5
2 es menor que 5
cesar@crb-server:~$
```
