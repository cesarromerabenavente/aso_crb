Ejercicio 1: Contar hasta 10 con for
Usa un bucle for para contar del 1 al 10 e imprimir cada número en una línea nueva.

Ejercicio 4: Contar números pares del 1 al 20 con while:
Usa while para mostrar los números pares entre 1 y 20.

Hacemos el script:
```bash
#!/bin/bash

num=1

while [ $num -le 20 ]
do
        if [ $(( num % 2 )) -eq 0 ]; then
                echo $num
        fi

        num=$(( $num+1 ))
done
```

Ejercicio 5: Suma de dígitos
Pide un número al usuario y usa while para sumar todos sus dígitos. Por ejemplo, 123 debería devolver 6.

Hacemos el script:
```bash
#!/bin/bash

echo "Inserta un número y sumaremos sus dígitos:"
read num
suma=0

while [ $num -gt 0 ]
do

        digito=$(( num % 10 ))

        suma=$(( suma + digito ))

        num=$(( num / 10 ))

done

echo "La suma de los dígitos es: $suma"
```

Ejercicio 7: Imprimir solo archivos .txt

Hacemos el script:
```bash

echo "Introduce la ruta de un directorio:"
read dir

if [ -d "$dir" ]; then

for archivo in "$dir"/*
do
        if [[ $archivo == *.txt ]]; then
        echo "$archivo es un fichero .txt"
        fi
done

else
echo "El directorio no existe"
fi
```

Ejercicio 8: Factorial de un número
Solicita un número al usuario y calcula su factorial usando un bucle for.

Hacemos el script:
```bash
#!/bin/bash

factorial=1
echo "Introduce un número y calcularemos su factorial:"
read num

for (( i=num; i>=1; i-- ))
do

        factorial=$(( $factorial*$i ))

done

echo "El factorial de $num es $factorial"
```

Ejercicio 9: Verificar contraseña
Usa until para pedir al usuario que ingrese una contraseña correcta, y repite hasta que la acierte.

Hacemos el script:
```bash
#!/bin/bash

buena=1234

echo "Introduce la contraseña:"
read contra

until [ $contra = $buena ]
do

        echo "Contraseña incorrecta. Vuelve a intentarlo"
        read contra

done

echo "Contraseña correcta"
```
