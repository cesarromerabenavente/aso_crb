En cada uno de los ejercicios se indica la cadena de entrada y la salida esperada. Debes indicar el comando o comandos necesarios para transformar la entrada en la salida.

Ejercicio 1: Limpieza básica (mayúsculas, minúsculas y espacios)

1. Normalizar a mayúsculas

Entrada: $sys = "Windows Server"
Salida: WINDOWS SERVER

```bash
PS C:\Users\Alumno> $sys = "Windows Server"
PS C:\Users\Alumno> $sys.ToUpper()
WINDOWS SERVER
```

```bash

administrator
```

7. Actualización de dominio

Entrada: $web = "www.miempresa.es"
Salida: www.miempresa.com

```bash
PS C:\Users\Alumno> $web = "www.miempresa.es"
PS C:\Users\Alumno> $web.replace('.es','.com')

```

OTRA FORMA MÁS GENERAL:

```bash
PS C:\Users\Alumno> $web = "www.miempresa.es"
PS C:\Users\Alumno> $web.Substring(0, $web.LastIndexOf('.')) + ".com"
www.miempresa.com
```

8. Censura de datos

Entrada: $tarjeta = "1234-5678-9012-3456"
Salida: 1234-5678-9012-XXXX

```bash
PS C:\Users\Alumno> $tarjeta = "1234-5678-9012-3456"
PS C:\Users\Alumno> $tarjeta.replace($tarjeta.Substring(15, 4),'XXXX')
1234-5678-9012-XXXX
```

Ojo que aquí la longitud especificada en el Substring no importa. Véase:

```bash
PS C:\Users\Alumno> $tarjeta = "1234-5678-9012-3456"
PS C:\Users\Alumno> $tarjeta.replace($tarjeta.Substring(15, 4),'X')
1234-5678-9012-X
```

También funciona:

```bash
PS C:\Users\Alumno> $tarjeta = "1234-5678-9012-3456"
PS C:\Users\Alumno> $tarjeta.Substring(0, $tarjeta.Length - 4) + "XXXX"
1234-5678-9012-XXXX
```

25. Inversión de fecha. Transforma formato europeo a formato base de datos ISO (YYYYMMDD) sin guiones.

Entrada: $euDate = "31-12-2023"
Salida: 20231231

```bash
PS C:\Users\Alumno> $euDate = "31-12-2023"
PS C:\Users\Alumno> $d, $m, $y = $euDate.Split('-')
PS C:\Users\Alumno> $euDate = "$y$m$d"
PS C:\Users\Alumno> $euDate
20231231
```

También:

```bash
PS C:\Users\Alumno> $euDate = "31-12-2023"
PS C:\Users\Alumno> $temp = $euDate.Split('-')
PS C:\Users\Alumno> "{2}{1}{0}" -f $temp[0], $temp[1], $temp[2]
20231231
```
